Race rules

  1. Same instant

    You pick a side. One order leaves for every venue at the same moment, from the same server, over connections that are already open.

  2. Real, but harmless

    Each order is priced so that it cannot trade. The venue still has to process it, but no position opens and no fee is paid.

  3. The clock stops at confirmation

    Timing ends when the venue reports the order as processed, not when it merely says "received".

  4. Check it yourself

    Where an order is a transaction on a public chain, the result links to it on that chain's explorer. The code is open source.

How each venue is measured

Every venue gets the same treatment wherever it allows it: a real order on the market you picked, sized near the venue's minimum and priced a little away from the market so that it cannot trade. Every venue, DreamDEX included, runs on mainnet. Elsewhere the order is immediate-or-cancel, the same path a market order takes.
